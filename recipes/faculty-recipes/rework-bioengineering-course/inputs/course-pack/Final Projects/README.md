# Final Projects — placeholder

The original course pack contained two Canvas submission archives
(`submissions (47).zip`, 99 MB and `submissions (49).zip`, 42 MB) — student
final-project files from ES 53 Fall 2025.

Those zips have been **omitted from the public repo for FERPA reasons** —
student work isn't ours to publish. The faculty member working on the course
revision can drop the original Canvas exports back into this folder locally
without committing them (see the repo's `.gitignore` if you want to belt-and-
suspenders that).

What the submissions typically contain:

- A written report (PDF or DOCX) — usually 6–12 pages, problem statement +
  background + model + results + discussion.
- A poster or slide deck (PPTX or PDF) summarizing the work.
- Source files for any simulation (MATLAB `.m`, sometimes Python `.py`).
- Sometimes a short video walkthrough (MP4).

The project topics in any given year span the full course material — cardiac
electrophysiology, vascular flow, pulmonary mechanics, renal transport, muscle
biomechanics — usually one organ system per group.
