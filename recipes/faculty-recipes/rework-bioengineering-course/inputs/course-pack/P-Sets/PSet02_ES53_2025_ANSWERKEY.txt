A few tips for MATLAB:

To plot in other colors besides the standard 7 you’ll need to tell MATLAB exactly what color you want in terms of
RGB color values that range from 0 to 1. For example, if you wanted a dark blue you could use the following
syntax:
>> plot(x,y,'color', [0 0 0.5])
If you wanted a light blue you could use:
>> plot(x,y,'color', [0.7 0.7 1])
Note that the three values correspond to RED, GREEN, and BLUE respectively, and are the amount of that color
scaled from zero to one. If you had [1 1 1] this would be white, and [0 0 0] would be black.

If you want to make your line thicker you would use the following syntax:
>> plot(x,y,'color', [0 0 0.5], ‘linewidth’,4)
Where 4 is the relative thickness. MATLAB defaults to a linewidth of 1 unless you specify it.
